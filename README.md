# INTRST Films Templates

Public, version-controlled template specifications used by the INTRST Films content production engine.

## Purpose

This repository contains reusable template definitions, schemas, layout rules, and rendering instructions. Brand assets are intentionally stored outside GitHub in the INTRST Films Google Drive.

## Template philosophy

INTRST Films does not use one universal layout. Each design type has a small family of approved variants so the production engine can match the visual treatment to the story.

### Initial design families

- `image-posts/` — single-image editorial posts
- `carousels/` — multi-slide narrative stories
- `youtube-thumbnails/` — long-form and premium video packaging
- `short-video/` — vertical short-form composition specs
- `longform-video/` — flagship documentary scene/layout specs

## Selection logic

n8n should select templates using:

1. content pillar
2. story angle
3. platform
4. asset availability
5. emotional tone
6. attention objective

The visual system must remain consistent with the locked INTRST Films brand standards while allowing composition variety.

## Asset policy

No production brand assets, logos, portraits, exports, or source media are stored in this repository. Those live in the INTRST Films Google Drive.
